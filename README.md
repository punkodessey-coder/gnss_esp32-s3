# GNSS ESP32-S3

Прошивка для ESP32-S3: приём NMEA от GNSS-модуля по UART, вывод координат на встроенный дисплей ST7789 и веб-интерфейс через собственную Wi-Fi точку доступа.

## Подключение

| GNSS-модуль | ESP32-S3 |
|---|---|
| TX | GPIO8 |
| RX | GPIO9 |
| VCC | 3.3V или 5V по документации модуля |
| GND | GND |

## Сборка и загрузка

1. Установите [PlatformIO](https://platformio.org/).
2. Откройте папку проекта в VS Code.
3. Подключите ESP32-S3.
4. Выполните `PlatformIO: Upload`.
5. Откройте Serial Monitor на 115200 бод.

## Использование

1. Подключитесь к Wi-Fi сети `ESP32-GPS`, пароль `12345678`.
2. Откройте `http://192.168.4.1`.
3. На странице доступны координаты, вкладка IMU и офлайн-карта с тайлами из папки `/maps` на microSD. Для каждой карты используйте структуру `/<имя>/<z>/<x>/<y>.png`.



## GPS UART

| GNSS-модуль | ESP32-S3 |
|---|---|
| TX | GPIO8 (RX ESP32) |
| RX | GPIO9 (TX ESP32, опционально) |
| GND | GND |

## Офлайн-карты microSD

Поместите тайлы в каталог `/maps/<имя_карты>/<z>/<x>/<y>.png` на microSD. В веб-интерфейсе выберите карту в списке «Офлайн-карта». Тайлы отдаются локально через ESP32; интернет для отображения загруженных тайлов не требуется.
