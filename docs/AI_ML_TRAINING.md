# Обучение AI/ML профиля GNSS

В устройстве сейчас работает лёгкий статистический детектор аномалий (Welford),
а не нейросеть. Он адаптирует среднее и дисперсию по ходу работы, пока не
обнаруживает отклонение. Это онлайн-адаптация в RAM: после перезапуска профиль
начинается заново.

## Обучение отдельного профиля

1. Включите сбор набора AI/ML и накопите хотя бы 30 строк, лучше несколько
   обычных сеансов в разных условиях. Не включайте заведомо плохие/аномальные
   измерения в нормальный набор.
2. Скачайте `ai_dataset.csv` с устройства.
3. На компьютере с Python 3 выполните из корня проекта:

   `python scripts/train_ai_model.py ai_dataset.csv`

4. Скрипт создаст `src/ai_trained_model.h`. Он использует медиану и MAD
   (робастную оценку разброса), исключает строки с anomaly=1 и не обучает
   HDOP/число спутников без FIX. Координаты и сами значения lat/lon в модель
   не попадают.
5. Закоммитьте сгенерированный заголовок в ветку `ai/ml` и соберите прошивку.
   В ней появится встроенный профиль; без этого шага устройство продолжит
   использовать онлайн-обучение.

Это обучение нормального профиля без размеченных классов, не нейросеть и не
доказательство обнаружения спуфинга/глушения. Модель компактна и занимает
несколько десятков байт. Для переобучения повторите процесс на новом наборе.
